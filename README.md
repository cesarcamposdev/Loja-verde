# Loja Verde - Plantas e Vasos

Projeto de um site chamado "Loja Verde."

 O objetivo foi criar a página de uma loja de plantas e vasos usando HTML e CSS.

## O que foi usado
- HTML: para criar a estrutura da página (cabeçalho, seções e rodapé)
- CSS: para estilizar as cores, fontes e organizar os cards dos produtos com Flexbox

## O que tem no site
- Menu de navegação no topo
- Banner com mensagem de destaque
- Lista de produtos organizados em cards
- Seção sobre a loja e informações de contato
